## 4. T2 PDF 公式解析压力测试

任务参数：

```json
{
  "backend": "pipeline",
  "method": "auto",
  "lang": "ch",
  "formula": true,
  "table": true,
  "image_analysis": true,
  "use_llm": true
}
```

结果：

```json
{
  "status": "failed",
  "error": "MinerU exceeded timeout of 1800 seconds."
}
```

关键日志：

```text
Layout Predict: 100% | 26/26
MFR Predict: 71% | 224/315
```

分析结论：

- `MFR Predict` 是 MinerU 的数学公式识别阶段。
- 该测试验证了复杂公式场景下系统不会无限运行，任务超时后会标记失败并保留日志。
- 前端可通过“命令行”标签看到实时进度；后端可通过 `/api/jobs/{job_id}/progress` 返回 `current=224`、`total=315`、`percent=71.1`。
- 若评测任务主要关注正文结构化，可关闭公式解析；若需要公式结果，建议提高超时上限或使用 GPU。

## 10. 新增增强模块验收方法

升级后，新任务会额外生成：

```text
agent_data/jobs/{job_id}/output/enhancement_report.json
```

该文件记录四个增强模块：

- `image_preprocess`：图像预处理，记录是否调用 OpenCV、图片质量指标、增强动作和增强图片路径。
- `financial_table_validator`：财报/密集数字校验，记录财务关键词、数字密度、疑似 OCR 混淆和异常数字格式。
- `chart_parser`：复杂图表候选解析，记录 chart/image 候选区域、图片路径和尺寸。
- `cross_page_merge`：跨页合并与指代分析，记录跨页表格候选和指代消解候选。

验收方式：

```text
GET /api/jobs/{job_id}/artifact/enhancement_report
```

前端也可在“增强”标签页查看模块状态、工具调用、跳过原因、风险提示和产物路径。
