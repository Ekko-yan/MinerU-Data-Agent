# 提交材料清单

本目录已整理 Data Agent 赛题提交所需材料：

| 材料 | 路径 | 说明 |
| --- | --- | --- |
| 系统部署与运行说明 | `docs/系统部署与运行说明.md` | 架构、环境、启动、测试、日志、复现方式 |
| API 接口说明 | `docs/API接口说明.md` | 接口、参数、返回格式、认证建议 |

复现入口：

```powershell
cd D:\vscodepro\MinerU
$env:OPENAI_API_BASE="https://bk.xiaozhiai.cc/v1"
$env:OPENAI_API_KEY="<YOUR_API_KEY>"
$env:OPENAI_MODEL="glm-4"
$env:DATA_AGENT_MAX_RUNNING_JOBS="1"
$env:DATA_AGENT_JOB_TIMEOUT_SECONDS="1800"
.\.venv_mineru\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8765
```

```powershell
cd D:\vscodepro\MinerU\frontend
$env:VITE_API_BASE="http://127.0.0.1:8765"
npm run dev -- --host 127.0.0.1 --port 5173
```

浏览器访问：

```text
http://127.0.0.1:5173
```

新增四类增强模块：

- 图像预处理。
- 财报/密集数字校验。
- 复杂图表候选解析。
- 跨页合并与指代分析。

新任务会生成 `enhancement_report.json`，可通过前端“增强”标签页或接口 `/api/jobs/{job_id}/artifact/enhancement_report` 查看。
